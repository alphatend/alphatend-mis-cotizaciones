# Mis cotizaciones · demo de alphatend

Una página para probar cómo funcionaría «✓ Ya coticé» en alphatend. Marcas la compra en la que ofertaste y alphatend la
sigue: cuando PanamaCompra abre las ofertas, te dice quién ofertó, a cuánto y en qué lugar quedaste, y cuando sale la
resolución, a quién se adjudicó.

- **El tablero** trae compras de ejemplo con empresas inventadas, y botones para adelantar el tiempo.
- **«Pruébalo con una de tus cotizaciones»** lee en vivo, desde el navegador, el pliego y el cuadro de propuestas de la
  API pública de PanamaCompra (`apisv3.panamacompra.gob.pa`). Del pliego no se leen los datos de contacto.
- Lo que se marca se queda en el navegador (`localStorage`). No hay servidor.

Es un solo `index.html`, publicado con GitHub Pages.
